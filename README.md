# Бот для учёта продаж + мини-приложение + таблица лидеров

Что внутри:
- **Telegram-бот** (aiogram) — присылает уведомления о продажах в групповой чат
- **Мини-приложение** (Telegram Mini App) — форма для внесения продажи и таблица лидеров (день/неделя/месяц/всё время)
- **База данных** SQLite — хранит пользователей и транзакции

Программировать не нужно. Ниже — пошаговая инструкция.

---

## Шаг 1. Создать бота в Telegram

1. Открой Telegram, найди **@BotFather**
2. Напиши `/newbot`, придумай имя и юзернейм (должен заканчиваться на `bot`, например `myteam_sales_bot`)
3. BotFather пришлёт **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохрани его, он понадобится

## Шаг 2. Разместить бота на хостинге (Railway — самый простой вариант, бесплатный пробный период)

1. Зайди на **https://railway.app**, зарегистрируйся через GitHub
2. Загрузи эту папку (`salesbot`) к себе на GitHub:
   - Зайди на **github.com** → New repository → назови, например, `salesbot`
   - Загрузи туда все файлы из этой папки (кнопка "Add file → Upload files", просто перетащи всё)
3. В Railway: **New Project → Deploy from GitHub repo** → выбери свой репозиторий `salesbot`
4. Railway сам увидит `Procfile` и `requirements.txt` и запустит проект
5. Во вкладке **Variables** добавь переменные окружения:
   - `BOT_TOKEN` = токен из Шага 1
   - `WEBAPP_URL` = временно оставь пустым, вернёмся к нему в Шаге 3
6. Во вкладке **Settings → Networking** нажми **Generate Domain** — Railway выдаст тебе публичный адрес вида `https://salesbot-production.up.railway.app`

## Шаг 3. Указать адрес мини-приложения

1. Возьми домен из Шага 2 и допиши к нему `/webapp/index.html`
   Пример: `https://salesbot-production.up.railway.app/webapp/index.html`
2. Вернись в Railway → Variables → впиши это значение в `WEBAPP_URL`
3. Railway автоматически перезапустит бота с новыми настройками

## Шаг 4. Запустить бота

1. Найди своего бота в Telegram по юзернейму и нажми **Start**
2. Появится кнопка **«📊 Открыть приложение»** — нажми, откроется форма для внесения продаж и таблица лидеров

## Шаг 5. Подключить бота к общему чату с работниками

1. Добавь бота в свой групповой чат с работниками
2. Дай боту права администратора (или хотя бы разрешение писать сообщения)
3. Напиши в этом чате команду `/setgroup` — с этого момента туда будут прилетать уведомления вида:

   ```
   🏆 Новый профит!

   👤 Продавец: Иван Иванов
   💰 Сумма: 1500₽
   💵 Доля: 1050₽
   📦 Товар: Robux 800
   ```

4. (Необязательно) Напиши боту в личку `/setcommission 70` — это значит, что воркер получает 70% с каждой продажи. Доля в уведомлении будет считаться автоматически. Если не задать — доля равна полной сумме продажи.

Готово. Каждый работник может писать `/start` боту лично, открывать мини-приложение и вносить свои продажи — они сразу попадают в таблицу лидеров и в общий чат.

## Как это расширить дальше (идеи)

- **Подтверждение продаж** — прежде чем запись попадёт в чат, ты как админ подтверждаешь её кнопкой ✅/❌ (защита от накруток)
- **Автоподсчёт комиссии** — если у сотрудников разный процент, бот сразу считает и показывает их заработок
- **Бейджи/ачивки** — "10 продаж за день", "лучший результат недели"
- **Еженедельный дайджест** — бот сам присылает итоги недели в чат по расписанию
- **Экспорт в Excel** — команда `/export`, которая присылает файл со всеми транзакциями

Если что-то из этого понадобится — просто попроси добавить, я допишу код.

## Если что-то не запускается

Самая частая причина — не задан `WEBAPP_URL` или он не совпадает с реальным доменом Railway. Проверь, что в конце адреса добавлено `/webapp/index.html` и нет опечаток.
